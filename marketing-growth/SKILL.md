# Marketing & Growth

No deliverable without: target audience, single message, and a measurable success metric. If any is missing, derive or ask — never produce generic copy.

## Campaign brief (always fill before producing assets)
```
Tujuan: <1 metrik: signup, trial, revenue — dengan angka target & deadline>
Audiens: <siapa persis, pain point utama, di mana mereka berada>
Pesan inti: <1 kalimat, benefit bukan fitur>
Kanal: <kenapa kanal ini untuk audiens ini>
CTA: <satu aksi>
Budget & durasi | Cara ukur: <event/UTM/kode promo>
```

## Copywriting rules
- Lead with the outcome the customer gets; feature after benefit.
- One idea per asset; one CTA. Cut every sentence that doesn't move toward the CTA.
- Match language/register to the audience (formal ID, casual ID, or EN) — state the choice.
- Claims must be true and verifiable; no fabricated testimonials, numbers, or "limited slots" that aren't real.
- Always produce 2–3 variants of the headline/hook for testing.

## SEO checklist (per page/article)
1. One primary keyword + 2–3 secondary; search intent identified (informational/commercial/transactional).
2. Title ≤ 60 chars containing keyword; meta description ≤ 155 chars with CTA.
3. H1 unique; H2s answer the sub-questions searchers ask.
4. Internal links to/from at least 2 relevant pages; descriptive anchor text.
5. Content answers the query in the first screen; depth beats length.

## Growth experiments
Frame every idea as: **Hypothesis** (if X then metric Y moves Z%) → smallest test → sample/duration → decision rule (ship / kill / iterate). Run experiments one variable at a time; log results even when they fail — killed hypotheses are inventory.

## Funnel review format
Report each stage with conversion %: visit → signup → activation → paid → retained. Identify the single biggest drop-off, propose max 3 fixes ranked by (impact × ease), not a laundry list.

## Scoring rubric before shipping any asset (0–2 each; ship at ≥ 8/10)
Audience-specific · single clear message · CTA obvious · measurable · claims verifiable.
